# Rostar Studio — Propuesta de nueva web

Vista previa del rediseño de [rostarstudio.com](https://rostarstudio.com) presentado a Rostar Studio.
No es la tienda oficial: no procesa pedidos ni pagos.

## Contenido

- `index.html` — la página completa (HTML + CSS + JS, sin dependencias).
- `images/` — fotos de campaña y producto de Rostar Studio.
- `robots.txt` — evita que la vista previa aparezca en buscadores.

## Publicar en GitHub Pages

1. Sube estos archivos a la raíz de un repositorio.
2. En el repositorio: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
3. En un par de minutos estará en `https://<tu-usuario>.github.io/<repositorio>/`.
